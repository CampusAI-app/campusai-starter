# Where the borrowed skills come from

The `campusai-product` skill is ours. The packs below are free and open source, from people whose
work sets the bar. They update often, so run the same command again every few weeks to get the
latest.

**Emil Kowalski** · github.com/emilkowalski/skills
Motion and design engineering. Includes `emil-design-eng`, `animate`, `review-animations` and
`animation-vocabulary` (the words for describing motion, useful when you know what you want but
not what it is called).

```bash
npx skills add emilkowalski/skills --global -y
```

**Jakub Krehel** · github.com/jakubkrehel/skills
Interface craft. `better-layout` is the one to reach for most, since layout and spacing is the
most common real problem. Also `better-typography`, `better-colors`, `better-ui`,
`better-writing` and `better-accessibility`.

```bash
npx skills add jakubkrehel/skills --global -y
```

**Jakub Antalík** · github.com/Jakubantalik/transitions.dev
Around thirty clean web transitions (dropdowns, modals, toasts, tabs), each with a reduced-motion
version built in. A different Jakub from the one above.

```bash
npx skills add Jakubantalik/transitions.dev --global -y
```
