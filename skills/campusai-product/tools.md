# The tools and what each one is for

| Tool | What it is for | Cost |
|---|---|---|
| **Claude, with Claude Code** | Where all the work happens. Claude Code is the Code tab in the Claude desktop app: the same Claude, but it can work with files on your computer, run things and put them online. | Pro plan, about $20 a month |
| **Wispr Flow** | Talk instead of typing. Hold a key, say what you think, and it writes it out cleanly. Feedback comes out better spoken than typed because you are not editing yourself. | Free tier |
| **Vercel** | Puts anything you build on a link anyone can open. Claude deploys it, and every update redeploys. | Free (Hobby) |
| **Supabase** | The database and file storage behind a small app, if your build needs to save anything. | Free (two projects) |
| **GitHub** | Where code and skills live. Read a repo before using it, and keep your own projects there. | Free |
| **Raylight** | Motion design in the browser, for product videos and animated demos. | Free plan (1080p, small badge) |
| **Mobbin** | Screens and flows from real apps, to see how others solved the same page. | Free tier is limited |

## Vercel, the one habit
After a deploy, open the link in a private window before sending it. If it asks you to log in to
Vercel, it is a preview link only you can see, not a public one. Ask Claude to put it on the
project's main domain instead.

## Raylight
For showing a change in motion, or making a short demo of a feature:
- Start from one of Raylight's templates, many of them recreations of well-known product films.
  Swap in a CampusAI screenshot from the demo instead of building a scene from nothing (borrow
  before build applies to video too).
- Claude can drive Raylight directly. It is already connected; the first time, type `/mcp` in a
  new chat and sign in. The free plan allows 50 Claude actions a week.
- Its template library is also good motion inspiration: exact timings and camera moves you can
  borrow for web animation.
- Rules for anything showing CampusAI: the real demo, never a drawn mockup, and no fake browser
  frame around it.

## Your feed
Instagram and X are a tool too. Follow the people in `creators.md` and your feed turns into a
stream of good components and ideas. Save what stops you, and ask Claude what makes it good and
where it could help a student.
