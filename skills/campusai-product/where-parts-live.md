# Where the parts live

Borrow before you build starts here. Look on these shelves before writing anything.

## Ours
| What | Link | Use it for |
|---|---|---|
| The demo | https://campusai-demo.vercel.app | The copy of CampusAI we experiment on. Pull colours, fonts and spacing from here. Screenshot it. |
| Elevations | https://elevations.vercel.app (sign in with Base) | Components already rebuilt for us, graded by the team. Check here first: the part you need may already exist. Search `elevations-catalogue.md` to find one by page or kind, then open its link. |
| Design Library | https://library-mu-murex.vercel.app | Jacob's wall of inspiration, plus the Parts view (thousands of components) and the Sources view (every library we use, by job). |
| Parts catalogue | https://parts-catalogue.vercel.app | Every component on our shelf, searchable, most with a live preview. |

## Component libraries (free, copy the code)

**Connected.** These eight are wired into Claude as one connection called `components`, so you can
search all of them at once and pull a part's real code without opening a browser. Ask "search the
component libraries for X" and Claude looks here first.

| Library | Link | Good for |
|---|---|---|
| Magic UI | https://magicui.design | Motion for lists, borders, docks, marquees |
| React Bits | https://reactbits.dev | Animated text, backgrounds and small effects (the biggest of the eight) |
| Motion Primitives | https://motion-primitives.com | Small, clean motion pieces: morphing popovers, animated numbers, panels |
| Animate UI | https://animate-ui.com | Animated versions of everyday parts: tabs, buttons, avatar groups |
| SmoothUI | https://smoothui.dev | Polished interactions, including AI reasoning and steppers |
| beUI | https://beui.dev | Product-shaped parts: schedulers, heat calendars, citations |
| prompt-kit | https://www.prompt-kit.com | Chat and AI interface pieces |
| Cult UI | https://www.cult-ui.com | Polished, unusual components, like the 3D carousel |

**Browse in the browser.** Not connected, still worth a look:

| Library | Link | Good for |
|---|---|---|
| shadcn/ui | https://ui.shadcn.com | Solid basic building blocks: buttons, menus, dialogs, tables |
| Aceternity UI | https://ui.aceternity.com | Bold, expressive sections |
| Vengeance UI | https://www.vengenceui.com | Glass docks, carousels, kinetic text. Jacob starred it. Its search is broken, so find the name on the site, then ask Claude to pull that one |
| transitions.dev | https://transitions.dev | Clean transitions: dropdowns, modals, toasts, tabs (also installed as a skill) |
| 21st.dev | https://21st.dev | A big community library with previews |

For icons, Iconify has nearly every icon set free: https://icon-sets.iconify.design

## How to ask Claude to use them

Not "build me a filter bar". Instead: "find two or three filter bar components from the libraries
in where-parts-live.md, show me how each one looks, then combine the best parts in CampusAI's
style."
