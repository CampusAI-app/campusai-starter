# The lines that never move

Everything else in this pack is judgement. These are not. Each one is here because breaking it
already cost us something.

## In anything we make
- **No em dashes** in product copy or anything written for Jacob. Use a period or a comma.
- **No monospace fonts**, anywhere.
- **No all-caps, wide-letter-spaced labels** above headings.
- **No fake browser frames** (the three coloured dots, a fake address bar) around a screenshot or
  video. Show it plain or link to the real thing.
- **No made-up numbers.** No invented stats, no fake "only 3 spots left", no fake "live" badges.
  If a number is on screen, something real has to produce it.
- **Show the real product.** Anything showing CampusAI uses the real demo, not a drawn mockup.

## With data and access
- **Never put real student data** (yours, a friend's, anyone's) into a prompt, a file or a build.
  Make up a sample student instead.
- **Never put a password, key or token in a file.**
- **Nothing goes public without Jacob seeing it first**: no posts, no changes to the real CampusAI
  code, nothing shown to students.

## What "looks generated" means

The biggest giveaway is not colour or font. It is everything being the same rounded card, the
same icon in a tinted square, the same pill badge, the same spacing. Recolouring does not fix it.
Reach for something with a point of view instead: a thin ruled list instead of a stack of cards,
a real table instead of a row of pills.

Other giveaways: purple-to-blue gradients, gradient text, glows on things that are not loading,
a centred hero with a blurry blob behind it, and every element bouncing in on scroll.

Words that read as AI-written, so we avoid them: delve, seamless, leverage, elevate, unlock,
empower, robust, streamline, cutting-edge, game-changer, effortlessly, supercharge, revolutionize.
Say the concrete thing instead. Buttons say what they do ("Save changes", not "Submit").

Before showing anything, one question: does this look decided, or generated?
