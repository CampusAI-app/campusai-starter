# The Elevations catalogue

Every component the Elevation Run has found and rebuilt so far, 482 of them. Search this
before building anything: the part you need may already exist, already adapted to CampusAI.
Each entry links to its live card, where you can watch it run and grade it.

Grouped by where it would go, then by kind. Newest rounds are on the site first.
"Licence" says whether the original can be reused. No licence listed means look and learn
from it, but do not copy its code.
